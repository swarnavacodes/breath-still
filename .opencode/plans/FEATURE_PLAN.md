# Breathing Exercise App — Feature Plan
Platform: Web app (clean, modern, responsive)

## 1. Exercise Types
- Relaxation / Calm
- Energizing / Focus
- Box Breathing
- Sleep / Recover
- Custom duration + cycle timing

## 2. Guided Session UI
- Animated breathing guide
- Phase labels (Inhale / Hold / Exhale)
- Timer + controls
- Optional audio cues

## 3. Habit Tracking
- Daily streaks
- Calendar view
- Session duration
- Weekly/monthly charts
- Pre/post mood check-in

## 4. Design
- Clean typography, soft gradients
- Smooth animations
- Dark/light mode

## 5. Storage
- LocalStorage
- Export/reset
